[2607.14945] Introspective Attention Modulation for Safe Text-to-Image Generation

arXiv 原文

一句话结论

本文提出了一种基于注意力的内省安全机制（Introspective Attention Modulation），旨在无需重新训练现代扩散 Transformer 模型的情况下，通过调节生成过程中的注意力分布来抑制不安全内容的产生。

解决的问题

现有的文本到图像生成安全机制存在显著缺陷：外部过滤方法易受对抗性提示攻击，基于训练的方法计算成本高且难以适配新架构，推理时方法往往需要重新训练并导致语义擦除，且这些方法缺乏对不安全内容产生机制的深入理解，仅作为事后补丁。

创新点

  • 提出了一种首创的基于注意力的内省安全机制，专为现代基于扩散 Transformer 的高质量图像生成模型提供推理时的安全保障。
  • 为图像合成过程中的注意力演化提供了独特的原则性指导，使模型能够在生成过程中自我审视并纠正不安全概念的形成。
  • 开发了识别和提取扩散 Transformer 图像合成过程中不安全注意力的机制，并利用稀疏逻辑回归器对其进行调节。
  • 实现了优化过程并设计了内省比率控制（introspection ratio control），以提供调节安全与质量之间权衡的手段。
  • 在 I2P、SneakyPrompts、MMA-Diffusion 和 UnlearnDiffAtk 等标准基准上进行了广泛评估，证明该方法在安全性和质量上均优于现有的主流安全方法。
  • 首次确立了基于注意力的调节对于现代扩散 Transformer 架构而言，比传统的概念擦除方法更为有效。

  • 提供了首个全面的多语言分析，揭示了 T2I 模型中存在的语言不平等现象以及跨维度的语言特定权衡差异。
  • 揭示了多种语言依赖的生成模式，表明生成行为不仅受文本语义影响，还受到语言特定先验知识的系统性影响。
  • 通过评估包括 Nano Banana、Z-Image 和 EasyText 在内的最先进模型，展示了非拉丁书写系统仍是导致文本渲染破碎或不可读的主要瓶颈。

[2608.11205] AdvFD: Boosting Visual Generation via Adversarial Fr'echet Distance Loss

arXiv 原文

一句话结论

本文提出了一种对抗性 Fréchet 距离（AdvFD）方法，通过引入可学习的对抗表示和真实特征白化技术，解决了传统 FD-Loss 在优化静态预训练编码器时导致的“Fréchet 黑客攻击”（即目标指标提升但视觉质量下降）问题。

解决的问题

片段指出 FD-Loss 依赖预定义的静态预训练编码器（如 Inception、CLIP）作为监督目标，这会导致生成器过度适应特定特征空间，从而产生“Fréchet 黑客攻击”现象，即目标指标改善但视觉质量下降且其他未训练编码器的分数变差。

创新点

  • 识别并定义了'Fréchet 黑客攻击'现象，即优化静态 Fréchet 目标虽然能提升目标指标，但会损害视觉质量及与其他表示的对齐效果。
  • 提出了对抗性 Fréchet 距离（AdvFD），通过补充一个对抗性学习的可表示表示，来暴露真实分布与生成分布之间的残留差异。
  • 引入了真实特征白化（real-feature whitening）技术，以归一化自适应特征空间的尺度和协方差几何，从而稳定对抗表示的学习过程。
  • 在 ImageNet 类条件生成任务上进行了广泛实验，证明 AdvFD 能有效减少视觉伪影，并一致提升训练指标及未参与训练的编码器的 Fréchet 分数。

  • 通过实验验证了该框架的鲁棒性和通用性，展示了其在 SDXL、FLUX.1 和 Qwen-Image 等多种不同架构的扩散模型上均具有超过 0.8 的 SRCC 和 0.9 的 AUC 预测精度。

一句话结论

本文提出利用扩散模型在特定输入条件下产生的“坍缩生成”（collapsed generation）现象，即独立随机采样收敛至视觉相似输出，作为一种非侵入式的指纹信号，以解决文本到图像扩散模型的知识产权归属验证问题。

创新点

  • 识别出“坍缩生成”作为扩散模型固有的行为特征，并将其跨随机生成的异常一致性形式化为一种非侵入式指纹信号，用于文本到图像模型的归属验证。

  • 基于早期去噪行为和训练动力学的洞察，构建了针对可控管道的连续嵌入指纹和针对托管 API 的自然提示词指纹，实现了高效的指纹构建。
  • 在多个基于 UNet 和 Transformer 架构的扩散模型家族上进行了评估，证明了该方法能有效区分独立训练的模型，且在微调、剪枝、量化及自适应查询干预后指纹仍具有可检测性。
